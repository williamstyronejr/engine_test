# Keyboard character data

The engine implements its own lookup, validation and label code. Checked-in
`engine/src/keyboard_data.inc` contains protocol character mappings derived from
the installed X11 `keysymdef.h` and Unicode 16.0.0 category ranges derived from
Python's standard `unicodedata` module. These are data tables, not linked libraries.
No generator, Python installation or data download is needed to build or run.

Regenerate explicitly with `python3 tools/make_keyboard_data.py` using a Python
installation with Unicode 16.0.0 data. `--check` verifies reproducibility against
the installed X11 header; its SHA-256 is recorded in the generated file. Header
updates or Unicode upgrades require review and may change the accepted vocabulary.
Only exact X11 mappings are imported, excluding approximate/deprecated mappings.

Sources: [X11 protocol](https://www.x.org/archive/current/doc/xproto/x11protocol.pdf)
and [Unicode data](https://www.unicode.org/versions/Unicode16.0.0/).
